## Defects

### HOST_AMBIGUOUS with DECOMMISSIONED duplicate hostnames

**Description:** When a hostname exists as both ACTIVE and DECOMMISSIONED records,
`project_adapter.py` could select the DECOMMISSIONED record, returning
`HOST_AMBIGUOUS` instead of resolving to the ACTIVE host.

**Fix:** Hostname resolution now prefers ACTIVE records over DECOMMISSIONED
duplicates in `project_adapter.py`.

**Impact on test counts:** Final agent suite on this RC is **967 passed /
5 skipped** (baseline 966 + one new ACTIVE-over-DECOMMISSIONED regression).

**Severity:** Functional correctness — resolved before RC close.
