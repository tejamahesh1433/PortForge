# PortForge v1.0.0 Release Notes (Private/Internal Release)

## Overview
PortForge v1.0.0 marks the first stable release of the local port discovery and conflict resolution engine. Built to operate entirely offline without cloud dependencies, PortForge brings deterministic networking environments and port allocation capabilities.

**This is a Private/Internal Release.** No public open-source license has been selected at this time.

## Features
- **Local Agent Discovery**: Zero-dependency agent capable of discovering currently bound ports.
- **Central Synchronization**: Centralized REST API for managing allocations and providing multi-host state alignment without cloud requirements.
- **Offline Reliability**: Works in fully airgapped environments (no NPM/PyPI or remote container registries required at runtime).
- **Security Hardenings**:
  - Enrollment Tokens for node registration.
  - Payload signature verification to prevent spoofing.
  - Hardened database schemas to prevent injection.

## Deprecations & Breaking Changes
- `run_gate1.py` and other early prototype tools have been removed in favor of the stabilized `portforge` CLI.
- API endpoints stabilize on the `v1` prefix.

## Testing & Verifications
- Comprehensive unit testing suite for Agent and Backend passed successfully (176 tests).
- Dashboard and frontend logic pass all linting, typechecking, and structural verifications (52 tests).
- E2E cross-host discovery and allocation workflows strictly verified.

## Known Limitations
- Docker build environment under WSL2/Windows may occasionally face DNS resolution failures inside intermediate containers.
- The system must have `PORTFORGE_ADMIN_BOOTSTRAP_TOKEN` defined to initialize.
