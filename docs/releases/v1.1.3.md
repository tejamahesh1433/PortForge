# PortForge v1.1.3

v1.1.3 focuses on public-readiness and security hardening.

## Security & Network Hardening
- **Safe Docker defaults**: Default Docker bindings (`docker-compose.yml`) are now localhost-safe. Operators intentionally running multi-host/LAN Central deployments must use the documented LAN binding configuration.
- **Privacy hygiene**: Generalized public documentation and scrubbed all private infrastructure details.
- **New documentation**: Added comprehensive `SECURITY.md` and `CONTRIBUTING.md` guides.
- **Onboarding improvements**: Generalized and improved `README.md` to help external users onboard smoothly.

## Licensing
- Officially adopted the **Apache License 2.0** for all repository contents and packages.

## Note on Architecture
- **No protocol change**: The agent-central wire protocol remains unchanged (protocol 1).
- **No contract change**: The agent contract version remains unchanged (contract 1).

## Hotfix
- Fixes an issue where the Apache-2.0 LICENSE file text was inadvertently truncated.
